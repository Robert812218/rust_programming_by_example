- Segmentation fault: Arises when a programmer tries to access some memory that is not available to its process
- Rust is:
  - Statically typed: every type must be known at compile time
  - Strongly typed: The type system prevents the programmer from some kinds of errors, e.g. using the wrong type for a function parameter
  - Prevents data races
- Rust also prevents data races: concurrent access to a variable where one is a write
- Rust doesnt have:
  - Null pointers
  - Data races
  - Use after free
  - Use before initialization
  - Goto
  - Automatic coercion of Boolean, numbers and enumerations

- struct: A type containing data
- enum: A type with different possible variants
- trait: A description of behavior 
- impl: Adding behavior to a type/implementing a trait

- An associated function belongs to the type itself. It does not take self.
/// 
impl Point {
  // Associated function
  fn new(x: i32, y: i32) -> Self {
    Self { x, y }
  }

  // Method
  fn print(&self) {
    println!("({}, {})", self.x, self.y);
  }

  // Easiest rule to remember:
  Point::something -> associated function
  p.something() --> method

  // And usually:
  // associated function -> Does NOT have self
  // method -> HAS self, &self, or &mut self
}
